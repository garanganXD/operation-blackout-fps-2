OPERATION BLACKOUT — a round-based tactical FPS (Counter-Strike-style: buy menu, economy, bomb plant/defuse, patrolling and holding bot enemies, headshots) built from scratch on the kit's three.js 0.187.0 with procedural textures and synth audio, no external assets.

## Run it

```sh
node main.ts --serve
```

Then open http://localhost:8080 in a desktop Chrome with WebGL 2.
